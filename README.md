# Agata Anna Nowak — Process Engineer

An English-language portfolio adapted from the React Three.js portfolio template
provided by the user. It presents Agata's planning, logistics, process
engineering, and supply-chain experience using details from her CV.

## Run locally

Requirements: Node.js 18 or newer.

```sh
npm ci
npm run dev
```

Vite prints the local development URL in the terminal.

## Build

```sh
npm run build
```

The production site is written to `dist/`.

## Template attribution

This project uses and adapts the
[reactjs18-3d-portfolio template](https://github.com/ladunjexa/reactjs18-3d-portfolio)
by Liron Abutbul. The template's MIT license is retained in [LICENSE](./LICENSE).
The original 3D models are accompanied by their license files in `public/`.

## Privacy

The portfolio includes the CV's email address for professional inquiries. It
does not publish the CV's phone number, street address, or date of birth. No
contact-form service or backend is configured.
